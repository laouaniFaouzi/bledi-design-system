# UI kit — Site vitrine Bledi

Recréation de la page d'accueil de https://bledilink-connect.lovable.app (texte relevé sur le site, capture longue fournie par l'auteur).

`Landing.jsx` reprend dans l'ordre : héro + carte de démonstration, « Un objet oublié peut vite devenir urgent », les 4 étapes,
les objets autorisés, la liste des interdits, le bloc voyageurs, la confiance, les routes, la FAQ dépliable, le CTA final et le pied de page.

Tous les textes sont ceux du site, mot pour mot. Le site n'utilise aucune photographie : le seul visuel est la carte de
démonstration du héro. N'ajoutez pas d'imagerie sans validation.

C'est le seul contexte où `--font-display` (serif) est employé — l'app produit reste entièrement en Outfit.
